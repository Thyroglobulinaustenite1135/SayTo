# راهنمای گام‌به‌گام انتشار SayTo در گیت‌هاب

این راهنما برای کسی نوشته شده که برنامه‌نویس نیست ولی می‌خواهد برنامه‌اش را در گیت‌هاب منتشر کند.
فقط کافی است مراحل را به ترتیب انجام دهید. زمان لازم: حدود ۱۵ دقیقه.

---

## مرحله ۱ — ساخت حساب گیت‌هاب (اگر ندارید)

1. به سایت [github.com](https://github.com) بروید.
2. روی **Sign up** کلیک کنید و با ایمیل خود ثبت‌نام کنید.
3. نام کاربری‌تان را جایی یادداشت کنید — در مراحل بعد لازم می‌شود.
   در این راهنما فرض می‌کنیم نام کاربری شما `USERNAME` است؛ هرجا دیدید آن را با نام کاربری واقعی خودتان عوض کنید.

## مرحله ۲ — ساخت ریپازیتوری (انبار پروژه)

1. وارد حساب گیت‌هاب شوید و روی علامت **+** بالای صفحه کلیک کنید و **New repository** را بزنید.
2. در فیلد Repository name بنویسید: `SayTo`
3. توضیح کوتاه (Description): `Offline voice typing for Windows — Persian & English`
4. گزینه‌ی **Public** را انتخاب کنید (تا همه بتوانند برنامه را ببینند و دانلود کنند).
5. **هیچ‌کدام از تیک‌های پایین (Add a README و…) را نزنید** — چون پروژه‌ی شما همین الان همه‌ی این فایل‌ها را دارد.
6. روی دکمه‌ی سبز **Create repository** کلیک کنید.
7. صفحه‌ای می‌آید که چند دستور نشان می‌دهد — نیازی به تایپ آن‌ها نیست؛ به مرحله‌ی بعد بروید.

## مرحله ۳ — اتصال پروژه به گیت‌هاب و ارسال (فقط یک بار)

فایل `publish-github.ps1` این کار را خودکار می‌کند:

1. پنجره‌ی **PowerShell** را باز کنید (در ویندوز منوی Start را باز کنید و بنویسید PowerShell و Enter بزنید).
2. این دو خط را کپی و در PowerShell جای‌گذاری (Paste: کلیک راست) کنید و Enter بزنید — به‌جای `USERNAME` نام کاربری گیت‌هاب خودتان را بنویسید:

```powershell
cd "$env:USERPROFILE\Desktop\sayto"
powershell -ExecutionPolicy Bypass -File scripts\publish-github.ps1
```

3. اسکریپت از شما **آدرس ریپو** را می‌پرسد. این آدرس را بدهید (با نام کاربری خودتان):

```
https://github.com/USERNAME/SayTo.git
```

4. اولین بار که گیت می‌خواهد به گیت‌هاب وصل شود، یک پنجره‌ی ورود باز می‌شود —
   روی **Sign in with your browser** کلیک کنید و وارد حساب گیت‌هاب شوید. همین!
5. وقتی پیام سبز موفقیت دیدید، پروژه‌ی شما در گیت‌هاب آنلاین است.
   در مرورگر به `https://github.com/USERNAME/SayTo` بروید و ببینید.

> نکته: اگر خواستید دستی انجام دهید، معادل همین سه دستور است:
> ```powershell
> cd "$env:USERPROFILE\Desktop\sayto"
> git remote add origin https://github.com/USERNAME/SayTo.git
> git push -u origin main
> ```

## مرحله ۴ — انتشار فایل نصبی (Release)

برنامه‌ی آماده‌ی دانلود (`SayTo-1.0.0-portable-x64.zip`) را در بخش Releases می‌گذاریم:

1. در صفحه‌ی ریپو در گیت‌هاب، از ستون سمت راست روی **Releases** کلیک کنید.
2. روی **Create a new release** کلیک کنید.
3. در قسمت **Choose a tag** بنویسید: `v1.0.0` و روی **Create new tag: v1.0.0 on publish** کلیک کنید.
4. عنوان (Release title): `SayTo 1.0.0 — Persian & English offline voice typing`
5. در کادر توضیحات می‌توانید این متن را بگذارید:

```
First release of SayTo 🎙️

- Offline speech-to-text for Windows (Persian & English)
- Live dictation + global hotkey typing into any app
- Portable single exe — no installation needed
- Models download on first run (~40–55 MB per language)

Download `SayTo-1.0.0-portable-x64.zip` below, extract, and run `SayTo.exe`.
> Windows SmartScreen may warn on first run (app is not code-signed):
> click "More info" → "Run anyway".
```

6. پایین صفحه در قسمت **Attach binaries**، فایل `dist\SayTo-1.0.0-portable-x64.zip` را با موس بکشید و رها کنید (drag & drop) و صبر کنید آپلود تمام شود.
7. روی دکمه‌ی سبز **Publish release** کلیک کنید. 🎉

از این به بعد هر کسی در صفحه‌ی ریپو شما، لینک دانلود مستقیم برنامه را می‌بیند.

## مرحله ۵ — زیباسازی صفحه‌ی ریپو (اختیاری ولی توصیه‌شده)

1. در صفحه‌ی اصلی ریپو، روی آیکون چرخ‌دنده (⚙) کنار کلمه‌ی **About** (بالای ستون راست) کلیک کنید.
2. در Description بنویسید: `Offline voice typing for Windows — Persian & English 🎙️`
3. در قسمت Topics این‌ها را اضافه کنید: `speech-to-text` `vosk` `persian` `farsi` `windows` `wpf` `csharp` `offline` `dictation` `voice-typing`
4. Save را بزنید.

## مرحله ۶ — وقتی در آینده برنامه را تغییر دادید

هر بار که تغییری دادید (مثلاً با کمک من)، برای به‌روزرسانی گیت‌هاب فقط این دو خط در PowerShell:

```powershell
cd "$env:USERPROFILE\Desktop\sayto"
git add -A
git commit -m "توضیح کوتاه تغییرات"
git push
```

و اگر خواستید نسخه‌ی جدید برنامه منتشر کنید:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

بعد مثل مرحله‌ی ۴، یک Release جدید با تگ `v1.0.1` (یا هر شماره‌ی بالاتر) بسازید و زیپ تازه‌ی داخل پوشه‌ی `dist` را آپلود کنید.

## سؤالات رایج

**آیا کسی می‌تواند کد من را تغییر دهد؟**
بله، چون مجوز MIT است هر کسی می‌تواند استفاده کند؛ ولی هیچ‌کس نمی‌تواند روی ریپوی شما چیزی بنویسد مگر اینکه شما اجازه بدهید.

**مدل‌های صوتی هم به گیت‌هاب می‌روند؟**
نه — حجمشان زیاد است و `.gitignore` جلویشان را می‌گیرد. هر کاربر موقع اولین اجرا، مدل را مستقیم از سرور Vosk دانلود می‌کند.

**اگر خطای authentication گرفتم چه کنم؟**
در ویندوز به **Credential Manager** بروید (Control Panel → User Accounts → Credential Manager → Windows Credentials) و هر ورودی مربوط به `git:https://github.com` را پاک کنید و دوباره push بزنید تا پنجره‌ی ورود باز شود.
